# Indicadores Ciclicos Mendoza - A. Miranda Puliafito TFdG (UNCUYO)
Código fuente en R para el cálculo del ICA e ICS de Mendoza, perteneciente a mi Trabajo Final de Grado para la Lic. en CIencia Política y Administración Pública (UNCUYO, 2026).
La base de datos que utiliza este Script se divide en dos archivos de Excel: 01 - Proxies base de datos y 02 - ICA base de datos. Para ejecutar el código correctamente, es preciso modificar los enlaces de búsqueda en el comando *setwd* según corresponda.
